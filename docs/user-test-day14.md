## 今日要回答的两个问题（测完必须写）

1. **同伴卡在哪一步？**
   答：卡在收藏之后——按下「☆ 收藏」后想找回收藏的菜，发现没有任何地方能看（详见「测试发现」第 1 条）。
2. **这一步你自己为什么没发现？**
   答：我是作者，知道收藏目前只是内存状态、收藏夹是「以后的事」，心里默认用户不会去找；而测试者不知道这些内部决策，他只按「按了收藏 → 应该能找回」的常识走。这就是作者盲区：**你脑补了系统的设计意图，用户只看系统呈现的行为**。

## 修复记录（今天只修一个）

- 选定修复的问题：**收藏的食物找不到**（用户选方案 A）
- 为什么选它：三条反馈里唯一的**功能闭环断裂**——收藏按下后无任何地方可回看，收藏形同虚设；且它正是「同伴卡在哪一步」的标准答案。
- 修复时的额外发现（比反馈本身更深）：Day 11 起收藏状态放 HomePage 的 useState（内存），**切换页面时 HomePage 卸载、收藏随之清零**。所以问题有两层：① 没有查看收藏的入口；② 就算有入口，切到那个页面时收藏已经丢了。
- 修法（最小版，不新建页面、不加导航项）：
  1. 收藏状态从 HomePage 上提到 App.tsx（路由壳永不卸载 → 收藏跨页面存活；刷新清空的 Day 11 边界维持不变）；
  2. 食物库列表头部加「★ 只看收藏（N）」开关，打开后列表只显示收藏的菜，复用 tag-chip 胶囊样式；
  3. 开关打开且无收藏时给引导文案（「去首页抽一道，点☆收藏试试」）。
- 改动文件：`src/App.tsx` / `src/pages/HomePage.tsx` / `src/pages/LibraryPage.tsx` / `src/styles/app.css`
- 构建验证结果：`tsc --noEmit && vite build` 通过，55 modules，✓ built in 668ms（2026-09-30）

## 测试发现（2026-09-30 实测记录）

真人测试反馈 3 条（同伴原意转述）：

1. **收藏的食物没有收藏夹，找不到**（高）——核实属实：收藏按钮与存储都在，但四个页面里没有任何地方能看到收藏列表，收藏成了「死胡同」。
2. **新增食物没法配图**（中）——核实半属实：表单其实有 emoji 配图栏，但「配图」标签让测试者以为是传图片。
3. **骰子可以做一个旋转动画**（低）——现状 rolling 阶段是静态 🎲 + 文案。
