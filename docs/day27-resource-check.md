### 步骤 C｜导出数据（三条通道，选 easiest 的一条）

| 通道 | 怎么走 | 适合 |
| --- | --- | --- |
| **控制台导出** | 数据库 → SQL 型数据库 → 选中表 → 导出 / 查询结果导出 | 想要一份 CSV 存档 |
| **接口拉 CSV** | 见下方命令（密钥只写在你本机的 `.env`，不进文档、不进仓库） | 想要可重复的导出方式 |
| **本地已有副本** | `db/schema.sql`（表结构）+ `db/seed.sql`（种子）+ `functions/`（云函数代码）已在 Git 仓库里 | 只想确认"丢了能重建" |

接口拉 CSV 的命令模板（在 bash 里跑，把密钥换成本机 `.env` 里的值，**不要写进任何文件**）：

```bash
BASE="https://doyoueat-d5g36rg7ia785b553.api.tcloudbasegateway.com/v1/rdb/rest"
KEY="<填你自己的 CLOUDBASE_API_KEY，不要提交、不要截图>"

for t in foods favorites ratings health_profiles; do
  curl -s -m 30 --retry 2 --retry-delay 2 \
    -H "Authorization: Bearer $KEY" \
    -H "Accept: text/csv" \
    "$BASE/$t?select=*" -o "$t.csv"
done
ls -l *.csv
```

> 说明：`Accept: text/csv` 是让 PostgREST 直接返回 CSV；`--retry` 是防网关抖动（Day 26 实测约 1/6 请求会挂）。跑完把 `*.csv` 放到工作区外或确认 `.gitignore` 已忽略，**不要提交进仓库**。
